시연 순서 보기
  1. 참여자 탭 01 — 오늘 수요라이브 12차 카드에서 ‘멤버십 무료 신청’을 보여 줍니다. 카드 왼쪽을 체크하면 오늘 회차도 같은 흐름으로 이어집니다.
  2. 지난 강의에서 11.17 DOC09·11.07·11.04 가운데 2~3개를 체크 → 화면 아래에 붙는 ‘선택한 N개’ 막대 확인 → [후기로 이어가기]. (모바일에서는 막대가 화면 맨 아래에 고정됩니다.)
  3. 02 후기 — 강의별로 관점 1·2·3 예시를 눌러 보거나 직접 한 줄 입력 → [피클에게 초안 부탁]. 소감이 다르면 See·Feel·Change 초안도 달라집니다.
  4. 각 카드의 ‘큐리어스에 후기를 등록했습니다’를 체크 → [전자책 신청으로].
  5. 03 전자책 신청 — 신청 대상과 항목을 훑고 [선택한 강의 신청 보내기]. 여러 건이 한 번에 접수됩니다. 11.18·11.17은 ‘전자책 시연용’으로 표시됩니다.
  6. 상단 [관리자 승인] — 알람 확인 → 전체 선택 또는 몇 건만 골라 [선택한 건 승인 및 발송]. 시연용 회차도 그대로 발송됩니다.
  7. 참여자 탭 04 — 지메일 목록에서 강의별 메일을 열고 [전자책 열기], [다운로드 확인]. 승인 전 메일을 누르면 대기 상태를 보여 줍니다.
  8. 시연이 끝나면 아래 [시연 초기화]로 처음 상태로 되돌립니다.
